# Design Context

Contexto de diseño del proyecto, definido según el protocolo de la skill
`frontend-design` y unificado con el sistema de diseño `hallmark`.

## Audience

Estudiantes hispanohablantes del curso «Programación de Base de Datos SQL» de
Oracle Academy (código DPSQL 47–50), incluido el autor del portafolio. Buscan
materiales de estudio organizados por lección, con nombres claros y descargables.

## Use cases

- Navegar el temario desde un panel lateral y ver los archivos de un tema.
- Encontrar rápidamente una lección o práctica concreta (búsqueda + filtros).
- Leer los PDF de las lecciones en el navegador, sin descargarlos.
- Descargar prácticas (DOCX), esquemas SQL (ZIP) y recursos del curso.

## Brand personality / tone

Cálido, vivo y directo, en clave de app de aprendizaje (registro Hum de
hallmark, referencia usehallmark.com/examples/hum-07): papel crema,
multiacento (pera, cian, coral), sans redondeada, píldoras y tarjetas
redondeadas, botones que responden a la presión. A pantalla completa con
panel lateral izquierdo. Sin serif, sin negro puro, sin emojis.

## Decisiones de stack y diseño

- **Stack**: HTML + CSS + JS Vanilla (sitio estático, según `ARCHITECTURE.md`
  de dicresoft: web informativa sin interactividad de backend).
- **Sistema de diseño**: hallmark (autoritativo: tema Hum, tokens, slop test)
  - `frontend-design` (jerarquía primero, sistemas antes que detalles) +
    `impeccable` (craft floor, modo _Operate_) + reglas de dicresoft (libro de
    estilo, Material Symbols, sin emojis).
- **Macroestructura**: Narrative Workflow adaptado a shell de aplicación —
  panel lateral con los temas del curso (00–20) + contenido por tema.
- **Tema**: Hum (catalog) — papel crema `oklch(97% 0.012 95)`, acento pera,
  cian y coral; Plus Jakarta Sans + JetBrains Mono.
- **Género**: playful.
