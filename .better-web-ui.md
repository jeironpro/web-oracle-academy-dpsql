# Design Context

Contexto de diseño del proyecto, definido según el protocolo de la skill
`frontend-design` y unificado con el sistema de diseño `hallmark`.

## Audience

Estudiantes hispanohablantes del curso «Programación de Base de Datos SQL» de
Oracle Academy (código DPSQL 47–50), incluido el autor del portafolio. Buscan
materiales de estudio organizados por lección, con nombres claros y descargables.

## Use cases

- Encontrar rápidamente la lección o práctica de un tema concreto del curso.
- Leer los PDF de las lecciones en el navegador, sin descargarlos.
- Descargar prácticas (DOCX), esquemas SQL (ZIP) y recursos del curso.
- Navegar secuencialmente por el temario (anterior/siguiente).

## Brand personality / tone

Técnico y académico, en clave editorial: papel cálido, serif de lectura,
hairlines en lugar de bordes de tarjeta, tipografía de datos en mono.
Restrained: sin gradientes, sin sombras blandas, sin adornos superfluos.
El acento (óxido) se usa como subrayador, nunca como bloque de color.

## Decisiones de stack y diseño

- **Stack**: HTML + CSS + JS Vanilla (sitio estático, según `ARCHITECTURE.md`
  de dicresoft: web informativa sin interactividad de backend).
- **Sistema de diseño**: hallmark (autoritativo: tokens, macroestructura,
  slop test) + `frontend-design` (jerarquía primero, sistemas antes que
  detalles, pulido al final) + `impeccable` (craft floor, modo *Read*) +
  reglas de dicresoft (libro de estilo obligatorio, Material Symbols, sin
  emojis en la UI).
- **Macroestructura**: Index-First (la página es el índice del curso).
- **Género**: editorial. **Tema**: custom — papel cálido + acento óxido.
- **Fuentes**: Newsreader (display) · IBM Plex Sans (cuerpo) ·
  IBM Plex Mono (outlier: rutas, metadatos, etiquetas técnicas).
